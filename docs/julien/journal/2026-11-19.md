## Problèmes et solutions

- **Le PDF du rapport ne se lisait pas directement** : `pdftoppm` absent. Solution : extraction du texte avec `pdftotext`.
- **`composer create-project laravel/vue-starter-kit` installait Laravel 12 et Tailwind 3** : le dernier tag du kit est ancien. Solution : `laravel/vue-starter-kit:dev-main`, comme l'installeur `laravel new`.
- **Le kit plante en mode non interactif** (question sur les fonctions d'authentification). Solution : `php artisan install:features --answers='{"auth_features":[...]}'`.
- **Retirer les passkeys cassait le build** (`PasskeyVerify.vue` introuvable, suppression incomplète du kit). Solution : garder les passkeys.
- **PHPStan s'arrêtait à 128 Mo de mémoire.** Solution : `memory_limit = 512M` dans le `php.ini` local.
- **`npm run check` reformatait la documentation Markdown.** Solution : `*.md`, `docs/**`, `consignes/**` ignorés dans `vite.config.ts`.
- **Le `.gitignore` de Laravel ignorait `.agents/` et `.claude/`**, donc les skills. Solution : seuls `.agents/skills/` et `.claude/skills/` sont suivis.
- **Mot de passe de l'utilisateur `postgres` oublié sur le PC fixe.** Non résolu : la procédure de réinitialisation (droits administrateur) est à faire par Julien ; reprise sur le PC portable à la place.
