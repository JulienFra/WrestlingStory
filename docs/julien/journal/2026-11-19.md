## Problèmes et solutions

- **Le PDF du rapport ne se lisait pas directement** : `pdftoppm` absent. Solution : extraction du texte avec `pdftotext`.
- **`composer create-project laravel/vue-starter-kit` installait Laravel 12 et Tailwind 3** : le dernier tag du kit est ancien. Solution : `laravel/vue-starter-kit:dev-main`, comme l'installeur `laravel new`.
- **Le kit plante en mode non interactif** (question sur les fonctions d'authentification). Solution : `php artisan install:features --answers='{"auth_features":[...]}'`.
- **Retirer les passkeys cassait le build** (`PasskeyVerify.vue` introuvable, suppression incomplète du kit). Solution : garder les passkeys.
- **PHPStan s'arrêtait à 128 Mo de mémoire.** Solution : `memory_limit = 512M` dans le `php.ini` local.
- **`npm run check` reformatait la documentation Markdown.** Solution : `*.md`, `docs/**`, `consignes/**` ignorés dans `vite.config.ts`.
- **Le `.gitignore` de Laravel ignorait `.agents/` et `.claude/`**, donc les skills. Solution : seuls `.agents/skills/` et `.claude/skills/` sont suivis.
- **Mot de passe de l'utilisateur `postgres` oublié sur le PC fixe.** Non résolu : la procédure de réinitialisation (droits administrateur) est à faire par Julien ; reprise sur le PC portable à la place.

- **`composer setup` lance `migrate`** : il échoue si la base ne tourne pas. Solution : `.env` et `docker compose up -d` avant `composer setup` (ordre écrit dans `AGENTS.md`).
- **L'installeur PostgreSQL sans écran exige un mot de passe**, qu'un agent ne doit pas choisir ni écrire. Solution : Docker, avec le mot de passe lu dans `.env` rempli par Julien.

- **Port 5432 déjà pris** par `chatapp_postgres` (ChatPulse, PostgreSQL 16). Solution : `DB_PORT=5433` dans `.env`, sans toucher au conteneur de ChatPulse.
- **`composer setup` a dépassé le délai de 300 s** pendant l'autoload. Solution : étapes finies à la main ; `COMPOSER_PROCESS_TIMEOUT=0` noté dans le skill.
- **Wayfinder ne trouvait pas `php` pendant le build** : terminal ouvert avant l'installation. Solution : PATH relu.
- **`npm install` modifie `package-lock.json`** (26 lignes) sur ce PC. Modification annulée ; à surveiller, `npm ci` l'évite.
- **Composer avertissait que `composer.lock` n'était pas à jour avec `composer.json`.** Cause : seule l'empreinte `content-hash` était périmée, aucun paquet à changer (`composer update --lock --dry-run` : « Nothing to modify »). Solution : `composer update --lock`, une ligne changée dans le lock, `composer validate` propre.
- **Le kit plantait (500) quand on envoie `email[]=…`** : Fortify fait `Str::lower` sur l'e-mail avant de le valider (inscription, mot de passe oublié), et notre limiteur de connexion aussi. Solution : middleware `EnsureEmailIsText` sur les routes Fortify, et test `is_string` dans `FortifyServiceProvider` (le limiteur passe avant les autres middlewares).
- **Avertissements Vue « Hydration mismatch » sur `AppLayout`** sous `composer dev` (SSR), aussi sur le tableau de bord non modifié : vient du kit. Non traité, à regarder plus tard.
