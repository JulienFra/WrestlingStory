## Problèmes et solutions

- **`php.new` installe un PHP « herd-lite » sans PostgreSQL** : PHP statique sans `pdo_pgsql` ni `pgsql`, et sans moyen d'ajouter des extensions. Solution : `winget install --id PHP.PHP.8.4 -e`, placer son dossier avant `.config\herd-lite\bin` dans le PATH utilisateur, puis créer `php.ini` à partir de `php.ini-development` avec `extension_dir = "ext"`, les extensions `pdo_pgsql`, `pgsql`, `intl`, `mbstring`, `openssl`, `curl`, `fileinfo`, `zip`, `sodium`, `gd` et `memory_limit = 512M`. Composer reste celui de herd-lite et utilise ce PHP.
- **Port 5432 déjà occupé sur le poste** : un autre PostgreSQL l'utilise. Solution : `DB_PORT=5433` dans `.env`, comme Julien.
- **Le terminal garde l'ancien PHP 8.4.0 (« require a PHP version >= 8.4.1 »)** : un terminal ouvert avant le changement de PATH garde l'ancien. Solution : recharger le PATH ou redémarrer l'application qui héberge le terminal.
- **21 tests de pages échouent pendant que `composer dev` tourne** : `public/hot` existe, Inertia tente le rendu serveur sur `[::1]:5173/__inertia_ssr` (`StrayRequestException`). Solution : arrêter `composer dev` avant `composer ci:check`, et supprimer `public/hot` s'il est resté après l'arrêt.
- **« Une seule rivalité en cours par catcheur » ne tient pas dans un index unique** : le catcheur peut être en colonne A ou B. Solution : contrainte d'exclusion PostgreSQL sur `ARRAY[wrestler_a_id, wrestler_b_id]` avec l'opérateur `&&` (extension `intarray`, de confiance, sans superutilisateur), limitée aux rivalités actives.
- **Le `migrate:fresh --seed` du sous-agent a effacé la base locale**, dont le compte de Florentin. Solution : se réinscrire ; à l'avenir, une consigne de lot dit de lancer `migrate:fresh` sur la base de test (`DB_DATABASE=wrestlingstory_test`), pas sur la base locale.
